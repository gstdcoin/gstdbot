⟩ Deploy
3 ways to deploy.

Auto installer, GitHub clone, or Docker. All work. All idempotent — safe to re-run.

1

Run the installer

Detects OS, installs Node.js, clones from GitHub, builds, configures, registers with platform.

curl -fsSL https://gstdbot.gstdtoken.com/install.sh | bash
2

Choose AI mode

☁️ Cloud (instant, Groq) • 💻 Hybrid (local+cloud) • 🔒 Sovereign (fully local)

Select [1/2/3] during install
3

Start the bot

Launch the gateway. Open dashboard. Start chatting.

cd ~/gstdbot && node dist/index.js
↻

Interrupted? Start fresh

The installer is idempotent — skips completed steps. Add --fresh to reset everything.

curl -fsSL https://gstdbot.gstdtoken.com/install.sh | bash -s -- --fresh
1

Clone & Build

Standard Node.js project. Requires Node.js ≥ 20.

git clone https://github.com/gstdcoin/gstdbot.git
cd gstdbot
npm install
cp .env.example .env # add your GROQ_API_KEY
npx tsc
2

Configure & Run

Edit .env, add Telegram bot token (optional), start the gateway.

# Edit .env: GROQ_API_KEY, TELEGRAM_BOT_TOKEN
node dist/index.js
3

Update anytime

cd gstdbot && git pull && npx tsc
# Restart your process
🐳

Docker Compose

Full stack in containers.

git clone https://github.com/gstdcoin/gstdbot.git
cd gstdbot
cp .env.example .env
docker compose up -d
