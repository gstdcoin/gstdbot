⟩ Installation Guide
3 simple steps. That's it.

Even if you've never used a terminal before — just follow these steps.

1

Open Terminal

Mac: Press ⌘ + Space, type "Terminal", press Enter.
Linux: Press Ctrl + Alt + T.
Windows: Install WSL first, then open it.

2

Paste this command & press Enter

Copy the line below, paste it into your terminal window, and press Enter. The installer does everything automatically.

curl -fsSL https://gstdbot.gstdtoken.com/install.sh | bash
3

Open your dashboard

After 1-2 minutes, the installer will show "READY". Open your browser and go to:

http://localhost:8080
💡

Something went wrong?

Just run the same command again! The installer remembers where it stopped and continues. Want to start fresh? Add --fresh

curl -fsSL https://gstdbot.gstdtoken.com/install.sh | bash -s -- --fresh
1

Clone & Build (requires Node.js ≥ 20)

git clone https://github.com/gstdcoin/gstdbot.git
cd gstdbot
npm install
cp .env.example .env
npx tsc
2

Start

node dist/index.js
3

Update anytime

cd gstdbot && git pull && npx tsc
🐳

Docker Compose — one command

Full stack in containers. Requires Docker.

git clone https://github.com/gstdcoin/gstdbot.git
cd gstdbot
cp .env.example .env
docker compose up -d
