⟩ Installation
5 minutes. Any device.

Automatic installer detects your OS, installs dependencies, configures wallet, and joins the Swarm. Choose your method.

1

Run the installer

One command detects your OS, installs Ollama + GSTD Node, generates wallet keys.

curl -fsSL https://gstdbot.gstdtoken.com/install.sh | bash
2

Configure your node

Interactive wizard: set node name, choose GPU/CPU mode, set resource limits.

gstd-node setup
3

Connect wallet

Auto-generates TON wallet or import existing. Link Telegram for Stars payments.

gstd-node wallet init
4

Start earning!

Node joins Swarm, processes tasks, earns GSTD. Open dashboard at localhost:8080.

gstd-node start --daemon
🐳

Docker Compose (recommended)

Full stack in one container: AI engine, wallet, dashboard, swarm node.

git clone https://github.com/gstdcoin/gstd-node.git
cd gstd-node
cp .env.example .env # edit NODE_NAME, WALLET_SEED
docker compose up -d
⚡

Quick Docker Run

Minimal single container for quick testing.

docker run -d --name gstd-node \
-p 8080:8080 -p 11434:11434 \
-v gstd-data:/data \
